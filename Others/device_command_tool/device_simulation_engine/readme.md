# cd_findcar_automation_engine
## 项目简介
**cd_findcar_automation_engine** 寻车自动化引擎项目，主要是为了解决寻车项目的自动化与设备端的设备数据交互、指令下发验证，还有场端的上报交互验证等问题而设计的

该项目基于Flask框架和sqlite数据库实现，采用分层设计，便于扩展和维护

项目设计实现的功能：
  - 模拟多种类型的设备与服务器交互，包括通道相机、车位相机、网络LED屏、LCD一体屏、Lora节点以及4字节节点等设备的注册，心跳，信息上报与接收服务器下发指令等功能
  - 启动一个接收上报的服务器，用于接收场端的上行数据，方便做上行数据校验

**所有设备均在引擎启动时自动初始化并连接，强制要求提前配置设备地址到环境，有注册包和心跳包的自动注册并持续心跳，可通过接口主动断开连接或心跳**

## 项目启动
1. ### 环境配置
   - 项目python环境版本3.8，依赖项在requirements.txt中，可直接使用pip install -r requirements.txt安装
   - 需要提前给运行环境（windows/linux等）配置好设备需要的静态IP地址，目前需要自己创建6个IP(通道相机、车位相机、网络LED屏、LCD一体屏、Lora节点以及四字节节点)
2. ### 修改配置文件
   - 配置好环境地址后，按照实际运行情况更改配置文件config_xxx.yml中的
     - 要连接的目标服务器地址：server.host
     - 所有设备的IP地址：devices_addr
   - 配置文件中其余配置项均不需要改动，保留默认值即可
3. ### 启动引擎
   - run.py为启动文件
   - 可以自行修改app.run(host="0.0.0.0", port=1777)这一句，0.0.0.0表示可以通过本机所有IP地址访问引擎，端口按需自行修改
   - 配置好后直接运行即可

## 实现的功能模块及功能

- **通道相机模块**：
  - 注册
  - 心跳
  - 上报告警
  - 上报告警恢复
  - 上报来去车事件
  - 上报后退事件
  - 上报交通流量
  - 自定义指令发送工具(可以自己构造content部分参数，按协议封装发送)


- **车位相机模块**：
  - 注册
  - 心跳
  - 上报有车无车
  - 上报来车去车
  - 上报车牌更新（支持自己上传图片/使用引擎内置图片两种模式）
  - 上报设备故障
  - 上报压线告警
  - 上报压线取消


- **网络LED屏模块**：
  - 注册
  - 心跳
  - 实时监听服务器对该屏下发的信息，解析后入库
  - 查询服务器下发的指令历史记录


- **LCD一体屏**：
  - 注册
  - 心跳
  - 实时监听服务器对该屏下发的信息，解析后入库
  - 查询服务器下发的指令历史记录


- **Lora节点模块**：
  - 节点下不同地址的探测器
    - 上报有车无车
    - 上报故障正常（7种故障状态）
    - 开启/取消持续上报状态


- **4字节节点模块**：
  - 节点下不同地址的探测器
    - 上报有车无车
    - 上报故障
    - 开启/取消持续上报状态


- 服务器接收上报模块：
  - 启动一个接收上报信息的接口，用于接收场端的上行数据
  - 接收后数据入库，分单车场接口和统一接口数据
  - 提供查询接口
