# Findcar Automation Engine

## 项目简介
**Findcar Automation Engine** 为寻车自动化引擎，主要是为了解决寻车项目自动化在设备交互端的设备数据交互、指令下发验证，还有场端的上报交互验证等问题而设计的

该项目基于Flask框架，采用分层设计，便于扩展和维护

项目设计实现的功能：
  - 模拟多种类型的设备与服务器交互，包括通道相机、车位相机、网络LED屏、Lora节点以及4字节节点等设备的注册，心跳，信息上报与接收服务器下发指令等功能
  - 启动一个云端服务器，用于接收场端上报的数据，方便做下发数据校验

**所有设备均在引擎启动时自动连接，有注册包和心跳包的自动注册并持续心跳，可通过接口主动断开连接或心跳**

## 项目启动
1. ### 环境配置
   - 需要提前给运行环境（windows或linux等）配置好设备需要的静态IP地址，目前需要五个IP(通道相机、车位相机、网络LED屏、Lora节点以及四字节节点)
2. ### 修改配置文件
   - 配置好环境地址后，按照实际运行情况更改配置文件config_xxx.yml中的
     - 要连接的目标服务器地址：server.host
     - 所有设备的IP地址：devices_addr
   - 配置文件中其余配置项均不需要改动，保留默认值即可
3. ### 启动引擎
   - 项目入口文件run.py，直接运行即可

## 支持的设备功能特性

- **通道相机模块**：
  - 注册
  - 心跳
  - 上报告警
  - 上报告警恢复
  - 上报来去车事件
  - 上报后退事件
  - 上报交通流量

- **网络LED屏模块**：
  - 注册
  - 心跳
  - 实时监听服务器对该屏下发的信息，并解析后显示

- **车位相机模块**：
  - 注册
  - 心跳
  - 上报有车无车
  - 上报来车去车
  - 上报车牌更新（支持使用引擎内置图片/自己上传图片两种模式）

- **Lora节点模块**：
  - 注册
  - 心跳
  - 节点下不同地址的探测器
    - 上报有车无车
    - 上报故障正常（7种故障状态）

- **4字节节点模块**：
  - **暂未实现**

## 项目主体结构（以通道相机为例）
```plaintext
Findcar Automation Engine/
├── app/
│   ├── __init__.py               # Flask应用初始化
│   ├── api/                      # API接口层（负责所有接口实现和数据类型转换）
│   │   ├── __init__.py
│   │   └── channel_camera.py     # 通道相机API
│   │
│   ├── connection/               # 连接模块（负责所有设备与服务器的连接，发送和接收，不处理任何业务和数据逻辑）
│   │   ├── __init__.py 
│   │   └── tcp_connection.py     # TCP连接管理
│   │
│   ├── log/                      # 日志目录（记录所有日志，按天分割文件夹，按小时分割文件）
│   │
│   ├── models/                   # 协议封装层（所有设备的协议封包、解包和包处理等，只负责数据不处理业务逻辑）
│   │   ├── __init__.py
│   │   └── channel_camera_model.py
│   │
│   ├── resource/                 # 内资资源层（主要放置内置图片等）
│   │
│   ├── services/                 # 业务逻辑层（所有设备的业务逻辑，如数据处理，组装，等待，业务条件等）
│   │   ├── __init__.py
│   │   └── channel_camera_service.py  # 通道相机业务逻辑
│   │
│   ├── utils/                    # 工具模块
│   │   ├── __init__.py
│   │   ├── logger.py             # 日志工具（采用loguru实现，自定义两个handler，一个负责标准输出一个负责文件输出）
│   │   └── config.py             # 配置加载工具（实现配置文件加载，支持yml文件）
│   │
├── config.yml                    # 配置文件
├── requirements.txt              # Python依赖库
└── run.py                        # 项目入口文件
